# تطبيق القاعدة النورانية للأطفال 🎈 (Offline Web App)

تطبيق ويب تعليمي تفاعلي متكامل ومستقل تماماً لتعليم الأطفال حروف وأصوات **القاعدة النورانية** بدون الحاجة لأي اتصال بالإنترنت.

---

## 📁 هيكلية ملفات المشروع:

```text
al-qaida-nooraniyya/
│
├── index.html                    # التطبيق بالكامل (HTML + CSS + Vanilla JS مدمجة 100%)
├── README.md                     # دليل الاستخدام والتشغيل
│
└── assets/
    ├── audio/                    # 1321 ملف صوتي بصيغة MP3 لنطق الحروف والدروس
    ├── images/                   # 39 صورة عالية الدقة بصيغة WebP لصفحات القاعدة الأصلية
    ├── all_lessons_data.json     # قاعدة بيانات الدروس الـ 17 والنصوص والتوقيتات مدمجة
    ├── audio_master/             # ملفات التوقيتات الدقيقة (Timeline JSON) لجميع الدروس الـ 17
    └── content/
        └── lessons/              # ملفات إحداثيات ومواقع الحروف على صفحات الكتاب (17 درس)
```

---

## 🚀 كيفية التشغيل:

### 1. التشغيل المباشر بدون إنترنت (الأسهل):
- اضغط نقراً مزدوجاً (Double Click) على ملف `index.html` مباشرة وسيفتح التطبيق فوراً في أي متصفح (Safari, Chrome, Firefox, Edge).
- يعمل بشكل كامل دون الحاجة لأي شبكة إنترنت.

### 2. التشغيل عبر خادم محلي (اختياري):
إذا رغبت بتشغيل التطبيق عبر شبكة محلية (مثل مشاركته مع أجهزة لوحية أو هواتف في نفس الشبكة):
```bash
cd al-qaida-nooraniyya
python3 -m http.server 8080
```
ثم افتح من أي جهاز: `http://localhost:8080` (أو بعنوان الـ IP الخاص بجهازك).

## ✨ المميزات الرئيسية للتطبيق:
1. **الدروس الـ 17 كاملة**: من الدرس الأول (حروف الهجاء المفردة) حتى الدرس السابع عشر (تدريبات عامة).
2. **واجهة أطفال مبهجة**: أزرار لمسية كبيرة، ألوان زاهية، وتصميم متجاوب مع الهواتف والأجهزة اللوحية والشاشات الكبيرة.
3. **تزامن صوتي ومرئي فوري**: توهج وإبراز فوري للحرف أثناء النطق.
4. **نمطان للتعلم**:
   - **نمط البطاقات التفاعلية**: بطاقات ملونة واضحة مع وسوم الحركات وأزرار التكبير.
   - **نمط صفحة الكتاب الأصلية**: تصفح وتفاعل مباشر فوق صورة صفحة القاعدة النورانية الأصلية.
5. **شريط تصفية ذكي**: في الدروس التي تحتوي على حروف مجمعة (مثل الدرس الرابع والخامس)، يمكن التبديل بين:
   - عرض الكل
   - الحروف الفردية فقط
   - تدريبات تجميع الحركات
6. **أدوات تحكم متقدمة**:
   - التشغيل المتتالي للدرس كاملاً (Play All).
   - تكرار النطق (مرة، مرتان، 3 مرات).
   - التحكم في السرعة (0.8x هادئ للأطفال، 1.0x طبيعي، 1.2x سريع).
7. **مسابقة الحروف التفاعلية (Quiz)**: لعبة "أين الحرف؟" مع أصوات تشجيعية واحتفال بالقصاصات الملونة (Confetti).
8. **نظام نجوم الإنجاز**: حفظ تقدم الطفل بعداد نجوم يُخزن محلياً على الجهاز.
